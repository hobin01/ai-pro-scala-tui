# 1. Main

`scala-agent`가 동작하지 않는 초기 화면(랜딩)이다. 사용자가 SCALA에 처음 진입했을 때 보는 화면으로, 가이드와 1차 진입 메뉴(데이터 취합 / 결과 확인 / 환경 설정)를 제공한다.

- 전체 레이아웃(Header / Content / Input / Footer)·색상·공통 컴포넌트는 `TUI-DESIGN.md`를 따른다.
- 기능 요구사항은 `FRD.md`의 `### 1.main.md`를 기준으로 한다.
- 인터랙션은 하이브리드: **선택 메뉴(↑↓·enter)가 1차 내비게이션**, 입력창은 `/` 커맨드·프롬프트용.

---

## State A — 초기 랜딩 (idle)

step 가이드(정적 템플릿)와 1차 진입 메뉴를 표시한다.

```
┌─ SCALA · Security Canonical Alignment & Lineage Automation ──────── idle ─┐
│                                                                          │
│  Welcome. SCALA normalizes heterogeneous SIEM data into OCSF and loads   │
│  it into OpenSearch with full document lineage.                          │
│                                                                          │
│  How it works                                                            │
│    1. Select 2+ data sources  (Elasticsearch / Splunk indices)           │
│    2. Review field & value samples                                       │
│    3. Confirm the agent workflow, then run the pipeline                  │
│                                                                          │
│  What would you like to do?                                              │
│    ▸ Collect & Normalize   run the normalization pipeline                │
│      View Results          lineage · workflow graph · monitoring         │
│      Settings              sources · indices · models · API key          │
│                                                                          │
├──────────────────────────────────────────────────────────────────────────┤
│ > _                                                                      │
└ ↑↓ move · enter select · /help · ctrl+c quit ───────────────────────────┘
```

- `▸` 마커 + 강조색으로 현재 항목을 표시한다. ↑↓로 이동, enter로 확정.
- 입력창은 `/` 커맨드와 프롬프트 입력에 사용한다. (예: `/help`, `/settings`, `/lineage-viewer`)

## State B — "View Results" 선택 시 (하위 옵션 펼침)

결과 확인은 3개 하위 기능을 가지며, 선택 시 펼쳐서 보여준다. 각 항목은 해당 커맨드/페이지로 전환된다.

```
│  What would you like to do?                                              │
│      Collect & Normalize                                                 │
│    ▾ View Results                                                        │
│        ▸ Lineage Viewer        /lineage-viewer                           │
│          Agent Workflow Graph  /agent-workflow                           │
│          Agent Monitoring      /agent-monitoring                          │
│      Settings                                                            │
```

## State C — `/help` 출력

`/help` 입력 시 Content 영역에 도움말을 표시한다.

```
│  SCALA — Help                                                            │
│                                                                          │
│  Commands                                                                │
│    /help              show this help                                     │
│    /lineage-viewer    trace a normalized document back to its source     │
│    /agent-workflow    view the agent workflow graph                      │
│    /agent-monitoring  token / cost / activity per agent                  │
│    /settings          open settings                                      │
│                                                                          │
│  Keys                                                                    │
│    ↑↓ move · ←→ paginate · space select · enter send                     │
│    ctrl+enter newline · ctrl+c quit                                      │
```

## State D — 무효 입력 (알 수 없는 커맨드)

존재하지 않는 커맨드 등 무효 입력은 입력창 위에 에러 라인(`✗`)으로 표시하고, 입력 내용은 유지하여 사용자가 수정할 수 있게 한다.

```
├──────────────────────────────────────────────────────────────────────────┤
│ ✗ Unknown command "/lineag". Try /help.                                  │
│ > /lineag_                                                               │
└ ↑↓ move · enter select · /help · ctrl+c quit ───────────────────────────┘
```

## 화면 전환

| 동작 | 전환 |
|---|---|
| `Collect & Normalize` 선택 | `2.source-selection` 화면 |
| `View Results > Lineage Viewer` (또는 `/lineage-viewer`) | `6.lineage-viewer` 화면 |
| `View Results > Agent Workflow Graph` (또는 `/agent-workflow`) | `4.agent-workflow-graph` 화면 (단순 조회 진입) |
| `View Results > Agent Monitoring` (또는 `/agent-monitoring`) | `7.agent-monitoring` 화면 |
| `Settings` 선택 (또는 `/settings`) | `8.settings` 화면 |
| `/help` | State C(도움말) 표시 후 메뉴로 복귀 |

## 페이지 고유 동작

- 이 화면의 메뉴/가이드 메시지는 정적 템플릿이다. (`scala-agent` 호출 없음)
- 입력창에 자유 텍스트를 입력하면 `Orchestrator Agent`가 의도를 확인한다. `/` 커맨드는 즉시 라우팅한다.
- `scala-agent`가 동작을 시작하면 이 화면을 떠나 `5.human-feedback`로 전환되며, **동작 중·동작 완료 상태의 화면은 `5.human-feedback`가 담당**한다.
- 동작 완료 후 `enter`로 돌아오는 "초기 화면"이 곧 State A다.
