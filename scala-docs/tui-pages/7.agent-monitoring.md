# 7. Agent Monitoring

`scala-agent`를 구성하는 에이전트들의 **모델 · 마지막 작업 이력 · 토큰 사용량 · 비용**을 모니터링하는 화면이다. 읽기 전용이다.

- 전체 레이아웃(Header / Content / Input / Footer)·색상·공통 컴포넌트는 `TUI-DESIGN.md`를 따른다.
- 기능 요구사항은 `FRD.md`의 `### 7.agent-monitoring.md`를 기준으로 한다.
- **실시간 조회는 하지 않는다.** 커맨드 실행 시점 스냅샷(`as of …`)을 표시하며, 갱신은 화면을 다시 열어 한다.
- 토큰 집계 범위는 **Session · Today · All-time** 3종이며, `←→`로 전환한다(각 scope가 한 페이지).
- `Load · Caching · Lineage`는 LLM을 사용하지 않으므로 **토큰 0 · 비용 $0**.

**scope 매핑**: **Session** = 현재 프로세스(앱 실행 후) · **Today** = 오늘 · **All-time** = 전체 기간(전체 프로그램). Session은 메모리, Today/All-time은 **PostgreSQL에 저장된 토큰/비용 사용 이력** 기반으로 계산한다.

```
│                                                                 │
│  Agent           Model        Last activity         Tokens  Cost │
│  ──────────────  ───────────  ───────────────────  ───────  ──── │
│  Orchestrator    gpt-…        showed final result   120,400 $0.61 │
│  Schema Profiler gpt-…-mini   profiled 13 fields    180,900 $0.27 │
│  Normalization   gpt-…        generated 13 rules    410,200 $0.89 │
│  Validator       gpt-…-mini   validated run         130,800 $0.17 │
│  Load            — (no LLM)   loaded 2,000 docs           0 $0.00 │
│  Caching         — (no LLM)   cached 5 mappings          0 $0.00 │
│  Lineage         — (no LLM)   recorded 2,000 docs        0 $0.00 │
│                                                                 │
├───────────────────────────────────────────────────────────────────┤
│ ⌧ read-only view                                               │
└ ←→ scope · ↑↓ scroll · enter → main · /help ───────────────────┘
```

- 상단 `Total`은 현재 scope의 전체 토큰·비용 합계와 마지막 run id.
- `Model`은 Settings의 agent별 model 설정값. `gpt-…`는 자리표시자다.
- `Last activity`는 각 에이전트의 최종 작업 이력. (예: Orchestrator "showed final result to user")

## 화면 전환

| 동작 | 전환 |
|---|---|
| 진입 | `1.main`의 "View Results > Agent Monitoring" 또는 `/agent-monitoring` |
| `←→` | scope 전환 (Session ↔ Today ↔ All-time) |
| `↑↓` | 표가 길 때 스크롤 |
| `enter` | `1.main` 화면으로 이동 |
| `/help` | 도움말 표시 |

## 페이지 고유 동작

- 읽기 전용 화면이라 텍스트 입력을 받지 않는다. (입력 영역은 `⌧ read-only view`)
- 수치는 커맨드 실행 시점 스냅샷이다. 실시간 갱신하지 않으며, 다시 열면 재계산한다.
- Cost는 `토큰 × 모델 단가`로 계산한다. 단가/모델은 Settings 값을 사용하며, no-LLM 3종(Load·Caching·Lineage)은 항상 $0이다.
- Session 값은 메모리에서, Today·All-time 값은 PostgreSQL 사용 이력에서 가져온다.
