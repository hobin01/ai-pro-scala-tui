# 6. Lineage Viewer

OpenSearch에 저장된 정규화 document의 **원본(raw) 데이터를 찾아 보여주는** 화면이다. PostgreSQL에 저장된 lineage 메타데이터로 추적한다.

- 전체 레이아웃(Header / Content / Input / Footer)·색상·공통 컴포넌트는 `TUI-DESIGN.md`를 따른다.
- 기능 요구사항은 `FRD.md`의 `### 6.lineage-viewer.md`를 기준으로 한다.
- **별도 agent 동작 없음** — PostgreSQL 메타데이터 + 소스/OpenSearch 직접 조회만 한다. 따라서 idle 상태에서 접근한다.
- lineage는 **문서(document) 단위**다. 메타데이터: 원본 source/index, 정규화 문서 source/index, 원본 doc id, OpenSearch `_id`, `run_id`.
- 조회 방식: **OpenSearch document `_id` 단건 조회**. (현재 범위에서는 가장 단순한 형태)

**입력/`enter` 규칙**: 입력창에 `_id`를 입력 후 `enter` = 조회. 결과를 본 뒤 **빈 입력 + `enter` = `1.main` 복귀**. (조회와 복귀가 같은 `enter`이므로, 입력이 비었을 때만 복귀로 분기)

---

## State A — 조회 프롬프트

```
┌─ SCALA · Lineage viewer ──────────────────────────────── idle ─┐
│                                                                │
│  Trace a normalized OpenSearch document back to its source.    │
│                                                                │
│  Enter an OpenSearch document _id to look up its lineage.      │
│  (find the _id in the OpenSearch dashboard link from a run)    │
│                                                                │
├──────────────────────────────────────────────────────────────────┤
│ > _                                                            │
└ enter lookup · empty enter → main · /help ────────────────────┘
```

## State B — lineage 결과 (원본 ↔ 정규화 추적)

상단에 메타데이터 추적, 하단에 **원본 raw 문서와 정규화 문서를 함께** 표시한다.

```
┌─ SCALA · Lineage viewer ─────────────────── _id: aZ12… · found ─┐
│  OpenSearch (normalized)                                       │
│    index  scala-normalized   _id  aZ12bQ8…   run_id  a1b2c3    │
│                                                                │
│  ▲ traces back to                                             │
│                                                                │
│  Source (raw)                                                  │
│    solution  Splunk · splunk-soc    index  main                │
│    doc id    _bkt=…::host::1234                                 │
│                                                                │
│  ─ Original raw document ───────────────────────────────────   │
│    clientip : "10.0.0.5"     port   : "443"                     │
│    status   : allow          _time  : 2026-06-25 01:02:03       │
│                                                                │
│  ─ Normalized document (OCSF) ──────────────────────────────   │
│    src_endpoint.ip   : 10.0.0.5      dst_endpoint.port : 443    │
│    activity_name     : allow                                   │
│    custom_attr       : { _time: "2026-06-25 01:02:03" }         │
│                                                                │
├──────────────────────────────────────────────────────────────────┤
│ > _                                                            │
└ enter: lookup another · empty enter → main · /help ───────────┘
```

- 상단 메타데이터는 PostgreSQL에서 가져온 추적 정보(원본 source/index/doc id ↔ OpenSearch index/`_id`, `run_id`).
- `Original raw document`는 메타데이터의 원본 위치(소스·index·doc id)로 ES/Splunk에서 가져온 실제 raw 문서.
- `Normalized document`는 OpenSearch에서 가져온 OCSF 정규화 문서. `custom_attr`로 매핑되지 않은 원본 필드가 보존됨을 함께 보여준다.
- 항목이 길면 `↑↓`로 스크롤한다.

## State C — not found

```
┌─ SCALA · Lineage viewer ─────────────── _id: zzz9 · not found ─┐
│                                                               │
│  ✗ No lineage found for _id "zzz9".                           │
│    - the id may be wrong, or                                  │
│    - the document was not produced by SCALA.                  │
│                                                               │
│  Check the _id in the OpenSearch dashboard and try again.     │
│                                                               │
├─────────────────────────────────────────────────────────────────┤
│ > _                                                           │
└ enter lookup · empty enter → main · /help ───────────────────┘
```

## State D — 조회 중 (로딩)

`_id` 입력 후 조회하는 동안 단계별 진행을 표시한다.

```
│  ⠹ Looking up lineage for "aZ12…"…                            │
│    ✓ metadata (PostgreSQL)                                    │
│    ⠹ fetching original raw document (Splunk · main)           │
│    · fetching normalized document (OpenSearch)               │
```

## 화면 전환

| 동작 | 전환 |
|---|---|
| 진입 | `1.main`의 "View Results > Lineage Viewer" 또는 `/lineage-viewer` |
| `enter` (입력에 `_id` 있음) | 해당 `_id`의 lineage 조회 (State D → B/C) |
| `enter` (입력 비어 있음) | `1.main` 화면으로 이동 |
| `↑↓` | 결과가 길 때 스크롤 |
| `/help` | 도움말 표시 |

## 페이지 고유 동작

- 이 화면은 `scala-agent`를 동작시키지 않는다. PostgreSQL 메타데이터 조회 + ES/Splunk raw 조회 + OpenSearch 정규화 문서 조회만 수행한다.
- lineage는 문서 단위로만 추적한다. (필드 단위 추적은 범위 밖)
- 조회 대상 `_id`는 보통 `5.human-feedback` 완료 화면이나 OpenSearch 대시보드에서 확인한 값을 사용한다.
- 한 번에 하나의 `_id`만 조회한다. (원천 index 이름 기반 검색 등은 현재 범위 밖, 추후 확장 가능)
