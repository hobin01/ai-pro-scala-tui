# 2. Source Selection

`Collect & Normalize`를 선택한 뒤 진입하는 화면이다. `8.settings`에 설정된 source 목록에서 정규화 대상 index를 **다중 선택**한다.

- 전체 레이아웃(Header / Content / Input / Footer)·색상·공통 컴포넌트는 `TUI-DESIGN.md`를 따른다.
- 기능 요구사항은 `FRD.md`의 `### 2.source-selection.md`를 기준으로 한다.
- 선택 규칙: **2개 이상** 선택해야 하며, **같은 솔루션 내 여러 index도 동시에 선택 가능**하다. 개수 상한은 없다.

**Content 설계**: source를 **SIEM(+연결 별칭) 단위로 그룹핑**하고, 그 아래 index를 체크박스로 나열한다. 마커는 `▸`(커서) + `[x]/[ ]`(선택), Header 우측에 `selected: N` 카운트, 하단에 솔루션별 내역 요약을 표시한다.

---

## State A — 소스 목록 (브라우징, 일부 선택)

```
┌─ SCALA · Select data sources ───────────────────── selected: 1 ─┐
│                                                                 │
│  Select 2 or more sources to normalize, then press enter.       │
│                                                                 │
│  Elasticsearch  ·  es-prod                                      │
│    ▸ [x] logs-2024                                              │
│      [ ] firewall-idx                                           │
│                                                                 │
│  Splunk  ·  splunk-soc                                          │
│      [ ] main                                                   │
│      [ ] security                                               │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│ > _                                                             │
└ ↑↓ move · space toggle · enter confirm · /help ────────────────┘
```

- `▸`는 커서, `[x]/[ ]`는 선택 상태. ↑↓로 이동, `space`로 토글.
- 선택 가능한 source는 `8.settings`(config)에 설정된 값과 항상 동일하다.

## State B — 2개 선택됨 (확정 준비)

선택이 2개 이상이 되면 하단에 확정 안내 라인(`✓`)을 표시한다.

```
│  Splunk  ·  splunk-soc                                          │
│      [x] main                                                   │
│      [ ] security                                               │
│                                                                 │
│  ✓ 2 sources selected — press enter to continue.                │
```

## State C — 무효 (2개 미만에서 enter)

2개 미만에서 `enter`를 누르면 에러 라인(`✗`)을 표시하고, 선택 상태를 유지한 채 재시도하게 한다.

```
│  ✗ Select at least 2 sources. (1 selected)                      │
├─────────────────────────────────────────────────────────────────┤
│ > _                                                             │
└ ↑↓ move · space toggle · enter confirm · /help ────────────────┘
```

## State D — 설정된 source 없음 (경계 케이스)

config에 source가 하나도 없으면 Settings로 안내한다.

```
┌─ SCALA · Select data sources ───────────────────── selected: 0 ─┐
│                                                                 │
│  No data sources are configured yet.                            │
│  Add sources in Settings, then return here.                     │
│                                                                 │
│    ▸ Open Settings   /settings                                  │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│ > /settings_                                                    │
└ enter open settings · /help ───────────────────────────────────┘
```

## State E — 같은 솔루션 내 2개 이상 index 선택 (예: Elasticsearch ×2)

같은 SIEM 아래 여러 index를 동시에 선택할 수 있다. 그룹 헤더 하나에 체크된 index가 여러 개 붙는다.

```
┌─ SCALA · Select data sources ───────────────────── selected: 2 ─┐
│                                                                 │
│  Elasticsearch  ·  es-prod                                      │
│      [x] logs-2024                                              │
│    ▸ [x] firewall-idx                                           │
│                                                                 │
│  Splunk  ·  splunk-soc                                          │
│      [ ] main                                                   │
│      [ ] security                                               │
│                                                                 │
│  ✓ 2 sources selected (Elasticsearch ×2) — press enter.         │
├─────────────────────────────────────────────────────────────────┤
│ > _                                                             │
└ ↑↓ move · space toggle · enter confirm · /help ────────────────┘
```

## State F — 3·4개 선택 (여러 솔루션 혼합)

개수 상한은 없다. 하단 요약에 솔루션별 내역(`Elasticsearch ×2, Splunk ×2`)을 표기해 같은 솔루션 다중 선택이 정상임을 명확히 한다.

```
┌─ SCALA · Select data sources ───────────────────── selected: 4 ─┐
│                                                                 │
│  Elasticsearch  ·  es-prod                                      │
│      [x] logs-2024                                              │
│      [x] firewall-idx                                           │
│                                                                 │
│  Splunk  ·  splunk-soc                                          │
│      [x] main                                                   │
│    ▸ [x] security                                              │
│                                                                 │
│  ✓ 4 sources selected (Elasticsearch ×2, Splunk ×2) — enter.    │
├─────────────────────────────────────────────────────────────────┤
│ > _                                                             │
└ ↑↓ move · space toggle · enter confirm · /help ────────────────┘
```

## 화면 전환

| 동작 | 전환 |
|---|---|
| `enter` (2개 이상 선택) | `3.data-samples` 화면 |
| `enter` (2개 미만) | State C(에러) 표시 후 현재 화면 유지 |
| `space` | 커서 위치 index 선택/해제 토글 |
| `←→` | source가 많아 한 화면을 넘어갈 때 페이지네이션 (`[n/m]`) |
| `/settings` | `8.settings` 화면 (source 추가/수정) |
| `/help` | 도움말 표시 |

## 페이지 고유 동작

- 선택 목록은 config 기반의 **정적 목록**이다. 이 화면에서는 실제 연결/데이터 fetch를 하지 않는다. (연결·샘플 확인은 `3.data-samples`에서 수행)
- index별 doc count는 표시하지 않는다. (카운트 쿼리 없이 정적 표기; 샘플은 `3.data-samples`에서 확인)
- `selected: N` 카운트와 하단 요약(`✓ N sources selected (...)`)은 선택을 토글할 때마다 즉시 갱신한다.
- 같은 솔루션 내 다중 index, 서로 다른 솔루션 혼합 모두 허용한다. 최소 제약은 "총 2개 이상"뿐이다.
