## [2026-06-28] PRD Mermaid 기준 agent graph 정렬

### Descriptions

- `scala-docs/PRD.md`의 Mermaid 워크플로우를 기준으로 backend LangGraph 구성을 수정했다.
- `src/scala_backend/agent_graph.py`에 Source SIEM, SIEM Connector, Orchestrator, Redis cache lookup, ChromaDB OCSF, Human Feedback loop, Processing Agents, OpenSearch, PostgreSQL 경로를 명시했다.
- cache hit 시 RAG/Validator/Human Feedback을 생략하고, cache miss 시 OCSF 후보 조회와 Validator 경로를 통과하도록 분기 테스트를 추가했다.
- `MappingDecider`가 실제 cache hit 수와 Human Feedback 요청 여부를 반환하도록 하여, `src/scala_backend/pipeline.py`가 실제 실행 결과를 바탕으로 LangGraph cache/feedback 분기를 호출하도록 수정했다. 일부 필드만 cached인 mixed 케이스에서는 cache-hit 경로와 cache-miss/feedback 경로를 모두 표현한다.
- `internal/app/view_pages.go`의 `/agent-workflow` 정적 화면을 PRD Mermaid 축약 표현으로 수정했다. Source SIEM, Future SIEM, cache hit/miss, Human Feedback loop, Processing Agents, 각 agent role/model을 표시한다. TUI는 아직 backend graph와 직접 연결하지 않고 정적 preview만 정확히 표시한다.
- `src/scala_backend/pipeline.py`의 진행 메시지는 LangGraph 방문 노드 수가 아니라 실제 Scala-agent 종류 수인 7개 기준으로 표시하도록 수정했다.
