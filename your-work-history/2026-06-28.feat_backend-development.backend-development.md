## [2026-06-28] PLANS.md 9번 백엔드 개발

### Descriptions

- Python 기반 SCALA 백엔드 패키지를 추가하고 `uv run scala-backend` CLI를 구성했다.
- TCP JSON-RPC 2.0 JSON Lines 서버를 추가해 `settings.get`, `settings.set`,
  `samples.fetch`, `pipeline.run`, `lineage.lookup`, `monitoring.query`를 처리한다.
- LangGraph 기반 7개 Scala-Agent 실행 그래프를 구성하고, pipeline 실행 중
  `feedback.request`, `progress`, `output.chunk`, `run.status` 흐름을 검증했다.
- PostgreSQL DDL migration, explicit dev seed, PostgreSQL repository, Redis mapping cache,
  OCSF 1.8.0 ingest/index, Chroma vector index, OpenAI provider abstraction을 추가했다.
- Elasticsearch/Splunk 실데이터 seed CLI를 추가하고, 실제 Elasticsearch/Splunk에서
  schema sample과 raw document를 읽는 connector를 구현했다.
- pipeline이 OpenAI/Chroma 기반 mapping 후보를 사용하고, Redis cache hit를 summary에
  반영하며, OpenSearch 적재 결과와 PostgreSQL lineage metadata를 통해 원천 데이터를
  역추적하도록 구현했다.
- Docker Compose backend infra 정의를 추가했다. Splunk는 arm host에서 amd64 image를
  사용하도록 `platform: linux/amd64`를 명시했고, 최신 Splunk 이미지의 General Terms
  승인 플래그와 API 기반 healthcheck를 반영했다.
- 실제 검증은 `.omo/evidence/backend-real-integration-9/`에 남겼다. 주요 증거는
  Docker compose up, migration/seed, OpenAI smoke, JSON-RPC E2E transcript,
  PostgreSQL/Redis/Elasticsearch/Splunk/OpenSearch/Chroma count, malformed JSON-RPC,
  OpenAI key secret scan이다.
